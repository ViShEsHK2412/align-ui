Edit mode — the contract

The tool measures and leaves the page as it found it. Edit mode breaks that promise on purpose, which is why it is off until armed, shown while it is on, and puts everything back when it is turned off. These are the parts of that promise that need a page which is really cascading, so they run here rather than in the unit tests.

They run on load. Everything below should say pass, and the last line should say the page is exactly as it started — because these checks edited it a dozen times while you were reading this.

By hand

Press Ctrl/Cmd + Shift + A to open the tool, then E to arm edit mode. The pencil inverts while it is armed — that is the only control in the bar that can change your page, and it is meant to look unlike the others. Press E again to disarm; everything it wrote goes back.
