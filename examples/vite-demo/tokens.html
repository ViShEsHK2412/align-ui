1 · On the scale, and off it

Both boxes look the same. Lock each and read the tokens row. 16 matches three tokens and all three are named, because picking one would be a guess. The second box has a 13px margin, which matches --text-sm — a margin matching a text token is a coincidence, and the readout says matches rather than from for exactly this reason.

5 · Type, on and off the scale

Press T with one of these locked. Line height is spacing, so it is measured like any other gap — and checked against the scale the same way.

Body text on the scale — 16px on a 24px line.

Nearly the same, but 15px on a 22px line.

Unitless 1.4 on 20px text, which resolves to 28.
